# Contribuer

1. Créez une branche courte (`correctif/...` ou `fonction/...`).
2. Ne placez aucune donnée réelle, sauvegarde ou secret dans Git.
3. Pour la base, créez une nouvelle migration avec `npm run db:generate`.
4. Lancez `npm run lint` et `npm test`.
5. Décrivez l'impact utilisateur et la vérification dans la demande de fusion.

Les déclarations restent anonymes par conception. Toute fonction proposant un nom d'élève ou un identifiant personnel doit être discutée avant développement.
